# 🎓 AI-Based Course Eligibility Assistant

This is an AI-powered web application that collects user information, initiates a voice call, and intelligently determines whether the user is eligible for a specific course. The system uses **React** for the frontend, **Flask (Python)** for the backend API, and integrates with **Vapi Assistant API** to perform real-time AI-driven conversations.

---

## 🚀 Features

- ✍️ Collects user information via a web form  
- 📞 Initiates a live voice call using Vapi Assistant API  
- 🧠 AI evaluates the user's spoken responses  
- ✅ Decides course eligibility dynamically  
- 🌐 Fully integrated frontend (React) + backend (Flask)  

---

## 🛠️ Tech Stack

| Layer        | Technology            |
|--------------|------------------------|
| Frontend     | React.js               |
| Backend API  | Flask (Python)         |
| Voice Agent  | Vapi Assistant API     |
| Hosting      | cPanel (optional)      |
